# FIC Assistente de Programação — Projetos JavaScript

Site-vitrine dos projetos desenvolvidos em sala de aula na FIC Assistente de Programação.

## Projetos demonstrados

- **Calculadora 301** — funções, DOM, expressões e tratamento de erros.
- **Color Lab** — RGB, inputs range, eventos e atualização dinâmica.
- **Desarmar a Bomba** — arrays, timers, estados, validação e dicas.
- **Aventura do Pixel** — Canvas 2D, gravidade, plataformas, moedas, inimigos, câmera e game loop.

## Formação

A página também apresenta informações da FIC, incluindo a qualificação profissional **Assistente de Aplicativos Computacionais e Sistemas para Internet**, eixo tecnológico **Informação e Comunicação** e carga horária de **300 horas**.

## Publicação

O site é estático e autocontido em `index.html`, pronto para publicação pelo GitHub Pages.
